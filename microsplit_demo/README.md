# MicroSplit demo

Here, we demonstrate the experimental API for MicroSplit.

> [!WARNING]  
> This tutorial makes use of a feature branch that is not yet part of a CAREamics
> release and may change with time, including be deleted after merging.

## Pre-requisite

- [uv](https://docs.astral.sh/uv/getting-started/installation/)
- [juv](https://github.com/manzt/juv)

## Run the notebook

You can run the notebook as a stand-alone using `juv` (pre-requisite):

```bash
juv run microsplit_demo.ipynb
```
