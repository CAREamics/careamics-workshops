# Using Noise2Void in CAREamics

In this section, we take a deep dive into Noise2Void using `n2v_in_depth.ipynb` or run 
simple example scripts. 

You can run the notebook as a stand-alone using `juv` (pre-requisite):

```bash
juv run n2v_in_depth.ipynb
```

Or the scripts with `uv`:

```bash
uv run 01_train.n2v.py
```

## Notes

The notebook explores Noise2Void in depth, while the scripts simply train Noise2Void in
different situation (uncorrelated noise, correlated noise) or Noise2Void flavour (Noise2Void
or structNoise2Void).
