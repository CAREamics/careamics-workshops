# CAREamics Fiji

In this section, we take a peek at the Noise2Void Appose plugin for Fiji. 

> [!WARNING]  
> This plugin is experimental and is not expected to be bug-free.

## Pre-requisite

- [Fiji](https://fiji.github.io/)

## Run

1. Download the `.jar` from the [careamics-fiji release](https://github.com/CAREamics/careamics-fiji)
2. Place it in your Fiji plugin folder
