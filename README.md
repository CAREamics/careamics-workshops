# CAREamics workshops

This repository contains material for workshops and demos of CAREamics features, algorithms
and entry points.

The main `pyproject.toml` is used dynamically but is not mean to be comaptible with
every example. For running particular notebooks or scripts, prefer running directly
with `uv`.

This repository requires `uv` for scripts and the `uv` plugin `juv` for notebooks.
